# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's advisory form](https://github.com/renkagod/osint-toolbox-mcp/security/advisories/new), not in a public issue. You'll get an answer as soon as the maintainer can look at it.

## Scope

This covers the server's own code: how it checks input, starts tools and returns their output, and the Docker image. Vulnerabilities in the bundled tools (Sherlock, SpiderFoot and the rest) belong to their own projects; once they are fixed there, open an issue here to update the pinned version.

Only the latest release gets fixes.
